## 一、基本规则

- **比赛用球**：40+ 塑料球，白色或橙色。
- **计分**：11 分制，每局先得 11 分且领先对手 2 分者获胜；10:10 之后每人轮流发球一分，必须净胜 2 分才能拿下该局。
- **局制**：单打常见七局四胜；团体赛中的单打多为五局三胜，具体以赛事规程为准。
- **发球**：球须从台面以上竖直抛起，高度不少于 16 厘米，不得遮挡；发球擦网后落入对方有效发球区则重发球；发球违例（遮挡、抛球不规范等）判失分。
- **轮换发球法**：一局比赛进行到 10 分钟仍未结束（双方均已至少得到 9 分的情况除外）时启用；此后接球方连续还击 13 板仍未得分，判发球方失分。
- **合法还击**：球越过或绕过球网装置后触及对方台面即为有效；连击、在球落地前台内拦截（拦击）判失分。

## 二、装备

### 球拍构成

- **底板**：纯木底板手感清晰、控球稳定；碳素底板更快更弹、借力更好。
- **海绵**：厚度与硬度直接影响持球时间、速度与旋转。
- **胶皮**：
  - **反胶**：表面光滑、摩擦强，适合弧圈结合快攻，是目前最主流的胶皮。
  - **正胶**：颗粒向外，击球速度快、球路下沉，适合快攻打法。
  - **生胶**：性能介于正胶与反胶之间，击球下沉、球路怪异。
  - **长胶**：颗粒较长，旋转变化诡异，多用于防守与削球打法。

### 握拍方式

- **横拍**：正反手均衡，适合弧圈球与全面型打法。
- **直拍**：手腕灵活、台内球处理好，近年直拍横打技术发展成熟。

### 其他装备

- **球鞋**：注重防滑与侧向支撑，避免急停变向时扭伤。
- **服装**：透气运动服；正式场地多为塑胶地胶。

## 三、基本技术

### 发球

平击发球、下旋发球、侧旋发球、侧上/侧下旋发球、高抛发球。

### 接发球

搓球（下旋过渡）、摆短、劈长、挑打、拧拉（横拍与直拍横打）。

### 进攻技术

正手攻球、正手弧圈球（前冲弧圈 / 加转弧圈）、反手拨球 / 直拍横打、反手弧圈。

### 防守与控制

推挡（直拍）、切球、削球、挡球、贴防。

### 步法

并步、跨步、交叉步、小碎步；注意重心交换与击球后的快速还原。

## 四、常用术语

- **旋转**：上旋、下旋、侧旋、侧上旋、侧下旋。
- **球台位置**：出台、台内球。
- **台内处理**：摆短、劈长、挑打、拧拉。
- **打法类型**：弧圈球、快攻、削球。
- **触网相关**：擦边、擦网、滚网。
- **落点**：近网、底线、中路、大角度。
- **节奏**：快带、借力、发力。

## 五、主要赛事

- **奥运会**：乒乓球单打与团体项目。
- **世界乒乓球锦标赛（世乒赛）**：单项锦标赛与团体锦标赛轮流举办。
- **世界杯**：单打世界杯与团体世界杯。
- **WTT 系列赛**：大满贯、冠军赛、球星挑战赛、常规挑战赛、总决赛。
- **国内赛事**：全运会、全国锦标赛、中国乒乓球俱乐部超级联赛（乒超）。

## 六、知名球星（举例）

- **中国男队**：马龙、樊振东、王楚钦、梁靖崑、林诗栋。
- **中国女队**：孙颖莎、陈梦、王曼昱、陈幸同。
- **海外选手**：波尔（德国）、奥恰洛夫（德国）、张本智和（日本）、林昀儒（中国台北）、雨果·卡尔德拉诺（巴西）、早田希娜（日本）、伊藤美诚（日本）。

## 七、学习建议

1. 先练基本姿势与步法，再逐项打磨单项技术。
2. 通过多球训练巩固动作定型，避免错误动作形成肌肉记忆。
3. 多看高水平比赛录像，学习线路选择与战术搭配。
4. 训练前充分热身，注意手腕、肩部与腰部的保护。
